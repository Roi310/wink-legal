Wink — SMS Opt-In Evidence

This page documents how Wink users consent to receive SMS verification codes. Consent happens inside the Wink mobile app (iOS/Android); there is no website form, keyword, or QR-code opt-in.

Opt-in method: In-app consent (Twilio campaign opt-in method: Other). The user enters their own mobile number and taps "Send code", which is the affirmative opt-in action.

What the user sees

During signup or sign-in, the user reaches the phone-verification screen, recreated below:

Verify your phone

Enter your mobile number and we'll text you a one-time verification code.

+1 (___) ___-____
Send code

By tapping "Send code" you agree to receive a one-time SMS verification code from Wink. Message frequency: only when you request a code. Message and data rates may apply. Reply STOP to opt out, HELP for help. See our Privacy Policy and Terms of Service.

Opt-in flow

  1. User installs the Wink app and creates an account (18+ age gate).
  2. On the phone-verification screen, the user enters their own mobile phone number.
  3. The user taps "Send code" — this tap is the explicit consent to receive one SMS verification code.
  4. Wink sends exactly one transactional SMS containing the verification code (valid 10 minutes).
  5. No marketing or promotional messages are ever sent. Codes are sent only when the user requests one.

Opt-out

Users can opt out at any time by replying STOP. Replying HELP returns help information. Every verification SMS includes "Reply STOP to opt out."
